CX Scorecard

Every customer-facing reply from Ivy and the CX team is scored each morning against the communication guidelines (9 checks). Pass rate counts pass and fail only: a check that didn't apply to a reply isn't counted either way.

What to fix

Each problem, how often it happened in this date range, and where it comes from in Intercom: a Fin procedure, a piece of guidance, a Fin setting, or a team member. The suggested change is a starting point to review, not something applied automatically.

    Runs

    A conversation already scored for a day is skipped unless it got new replies, or the guidelines version changed. Up to 31 days per run. Runs work through a batch every 2 minutes.

    Morning digest

    After each scheduled run, Flo DMs these people in Google Chat: pass rate for Ivy and the team, the weakest check, and the worst replies with a suggested rewrite and an Intercom link. Someone must have opened a chat with Flo once for it to reach them.

    How much to trust the scores
    
      
    You score a set of conversations by hand (the golden set below). A calibration run re-scores them with the current model, prompt and guidelines and shows how often it agrees with you, check by check. Run it whenever the guidelines, prompt or model change. It doesn't change any daily scores. Cost: about 2–3¢ per conversation.
