CX Scorecard

Every customer-facing reply from Ivy and the CX team is scored each morning against the communication guidelines (9 checks). Pass rate counts pass and fail only: a check that didn't apply to a reply isn't counted either way.

    Failures

    Fin change log

    Log each change to Fin (guidance, procedures, content, settings). Each one is marked on the trend chart, so you can see whether it moved the scores.

    Runs

    A conversation already scored for a day is skipped unless it got new replies, or the guidelines version changed. Up to 31 days per run. Runs work through a batch every 2 minutes.

    "Right voice" rules

    Rules waiting on an open decision in the guidelines start switched off.

    Changes apply to the next run. Scores already saved keep the settings they were scored with.

    Exclusions

    Conversations from these senders aren't scored. Spam, Fin preview tests and conversations with no reply are always skipped. A domain also covers its subdomains. Shopify contact forms are matched on the real customer, not mailer@shopify.com.

    Guidelines

    The version scores are judged against. Each score records its version. Saving a new version makes it active from the next run; days already scored are re-scored only when you run them again.
